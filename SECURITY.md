# Security

Mobile Serve makes a server on your computer reachable from your network, so problems in how it does
that matter. Examples: its own server for plain HTML serving a hidden file or one outside the
folder, or Mobile Serve stopping a process or running a command it shouldn't.

To report one, use **Report a vulnerability** on the repository's
[Security tab](https://github.com/ManonLef/mobile-serve/security), which keeps the report private
until it's fixed. Please don't open a public issue for it.

Only the latest release gets fixes.

That a shared server can be opened by every device on the network is how the extension works, not
a vulnerability: see [Security](README.md#security) in the README.
